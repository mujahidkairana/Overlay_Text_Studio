# Local SFX assets

Normal rendering never downloads sound files. To enable an explicitly requested
SFX, place a commercially safe WAV file here using one of these names:

- `soft_hit.wav`
- `subtle_whoosh.wav`
- `tick.wav`
- `low_riser.wav`

Only use self-created, CC0/public-domain, or otherwise licensed-for-commercial-use
audio. Record the source and license in this file before distributing an asset.
