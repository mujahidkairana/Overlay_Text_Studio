OVERLAY TEXT STUDIO v3.0.0 - QA SUMMARY

IMPLEMENTED PHASES
- Phase 0: repository-wide daily branch sequencing and collision checks.
- Phase 1: SRT input/parser, rich overlay schema, and backward-compatible persistence.
- Phase 2: cached FFmpeg hard scene-cut detection.
- Phase 3: deterministic semantic planning, density presets, cooldowns, and reporting.
- Phase 4: timing-safe subtle punch-in and mild temporary dim/focus.
- Phase 5: in-place freeze, optional local SFX, section treatment, and variation report.
- Phase 6: regression, Windows smoke checks, UI smoke, and documentation.

AUTOMATED AND RENDER VALIDATION
- Full 69-test unittest suite passes on the bundled Windows runtime.
- Headless Streamlit startup completes with zero UI exceptions.
- Real FFmpeg hard-cut test detects a black-to-white cut and reuses its cache.
- Scene analysis uses `-fps_mode vfr`; a simulated analysis failure continues safely with a warning.
- Punch-in render preserves exactly 60 frames for a 2-second 30-fps clip.
- In-place freeze preserves 2.0-second duration, 60 frames, and source audio.
- Multiple freezes in one chunk preserve exact duration, 120 frames, and audio.
- Local SFX mix preserves source duration and audio, uses 12% gain, and applies a limiter.
- User SFX folders require WAV files plus a README/license record.
- A real 10-minute acceptance render preserves 600 seconds, 18,000 frames, and audio.
- A true enhanced acceptance render combines SRT validation, a detected hard cut,
  semantic overlays, eased punch-in, dim/focus, freeze, licensed SFX, audio, and frame checks.
- The branch helper is tested against real local/bare repositories, increments
  across features, rejects collisions, and emits slash-separated Windows dates.
- End-to-end resumable render and short-source-audio regressions pass.
- Final verification still checks duration, FPS, dimensions, and expected audio.

BACKWARD COMPATIBILITY
- Legacy four-column CSV/XLSX inputs remain supported.
- Old project.json files without srt_path or editorial fields reopen successfully.
- Existing caption-safe top placement, encoder selection, and chunk resume remain active.

OFFLINE / SAFETY CHECK
- Normal use requires no cloud API, API key, LLM, generative model, or download.
- Scene analysis and effects use local FFmpeg/OpenCV only.
- The lower subtitle band remains protected even during SRT gaps.
- Source audio is not ducked; optional local WAV SFX are mixed conservatively on top.
- Missing optional SFX assets fall back safely to no added sound.

EDITORIAL / VIEWER ACCEPTANCE
- All specified semantic types have distinct, restrained visual treatments.
- Long SRT gaps promote suitable existing overlays into section cues without
  generating new claims or wording.
- Measured motion/detail scores suppress strong effects in visually busy shots.
- Rolling event density targets 4-7 per minute and reports over-target source data.
- Calm/Standard/Energetic presets cap strong actions and SFX independently.
- Resolved plan exports include action frames, section cues, motion, and detail scores.
- A real-footage contact sheet was visually inspected for hierarchy, centering,
  rounded-plate coverage, contrast, consistency, and caption-safe placement.
- Punch-in ramps are smooth, DIM_FOCUS and SFX have separate cooldowns, short
  WARNING plates include the CAUTION label width, and auto output matches source resolution.

WINDOWS SMOKE STATUS
- Tests ran on Windows using the application's configured shared Python and FFmpeg.
- Streamlit widget construction, FFmpeg filters, hard-cut cache, punch-in, freeze,
  SFX mix, frame count, duration, and audio presence were exercised locally.
